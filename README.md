# Personal Portfolio Website

This is a simple personal portfolio website. The site demonstrates my skills in HTML, CSS, JavaScript, and responsive web design.

##  Live Website
https://jjk557aidan.github.io/Github-Portfolio-/index.html




##  Features

- Multi-page website (Home, About, Contact)
- Responsive design for desktop and mobile
- Contact form connected to Supabase database
- Consistent navigation across all pages



##  Technologies Used

- HTML
- CSS
- JavaScript
- Supabase



##  Project Structure

- index.html - Homepage
- about.html - About page
- contact.html - Contact form page
- style.css - Website styling
- script.js - Contact form functionality
